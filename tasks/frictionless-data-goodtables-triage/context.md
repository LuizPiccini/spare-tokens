# Context

Frictionless Data tooling helps validate and publish tabular data packages. Stale issue triage is a useful AI-ready task because the output is not a code change; it is a structured artifact a maintainer can skim.

Review a small batch of public issues related to Goodtables, validation behavior, or tabular package checks. Classify each issue:

- duplicate
- already fixed
- still reproducible
- needs maintainer clarification
- not enough information

Do not post comments automatically.
