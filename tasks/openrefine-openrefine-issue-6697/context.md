## Issue Body Excerpt
When using the recon suggest widget in some field (such as manually selecting a recon candidate), it would be helpful if we could visit the page for the recon candidate without selecting it for matching.

### Proposed solution

Enable the "middle click" on suggested entities so that their page opens in a new tab.

Not sure?
